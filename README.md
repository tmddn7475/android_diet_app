개발기간 = 2022년 9월 ~ 12월

학교 강의에서 팀프로젝트로 만들었던 다이어트/피트니스 앱입니다.

**역할**
---------------
- 운동하기, 칼로리 계산 화면 구현
- 목표 설정과 몸무게, 칼로리 입력 후 저장 구현
- MPAndroidChart를 통한 몸무게 변화 시각화
